# 面相痣相解读

面相中痣的位置不同，吉凶寓意各异。传统相学认为「面无善痣」，但也有藏吉之痣。

---

## 痣相通则

1. **吉痣特征：** 黑亮有光泽、微微凸起、藏于不明显处（如眉内、耳内）
2. **凶痣特征：** 灰暗无光、扁平塌陷、明显暴露处（如鼻头、眼皮正中）
3. **中性痣：** 颜色正常、不明显凸起、位置一般

---

## 额部痣相

| 位置 | 含义 |
|------|------|
| 额头正中（天庭） | 少年得志或早年有特别机遇；但若痣色暗淡，则少年运势受阻 |
| 额头左侧 | 父亲对自己影响深远，或早年得到男性贵人相助 |
| 额头右侧 | 母亲对自己影响深远，或早年得到女性贵人相助 |
| 印堂（两眉之间）有痣 | 「二龙戏珠」，有才华但心思多变，情绪起伏大 |
| 眉毛上方 | 兄弟姐妹中有特别突出者 |
| 太阳穴 | 外出运强，适合异地发展 |

## 眉部痣相

| 位置 | 含义 |
|------|------|
| 眉内藏痣（被眉毛遮住） | 聪慧有智谋，藏而不露，是吉痣 |
| 眉头有痣 | 性格中有执念，或与某位兄弟/朋友缘分特殊 |
| 眉尾有痣 | 人缘好，但要注意口舌是非 |
| 眉上有痣 | 为人重感情，可能因朋友之事操心 |

---

## 眼部痣相

| 位置 | 含义 |
|------|------|
| 眼头（内眼角）有痣 | 感情细腻专一，但容易为情所困 |
| 眼尾（鱼尾/妻妾宫）有痣 | 感情经历丰富或婚姻中需要用心经营 |
| 上眼皮有痣 | 家中容易有变动，或田宅方面需注意 |
| 下眼皮（泪堂）有痣 | 为子女操劳多，或子女缘分特殊 |
| 卧蚕有痣 | 桃花运旺盛，但感情选择需谨慎 |
| 眼白有痣 | 性格中有特别的执念或偏好 |

## 鼻部痣相

| 位置 | 含义 |
|------|------|
| 山根（鼻梁起点）有痣 | 中年有健康方面的考验，或事业根基有过动摇 |
| 鼻梁有痣 | 事业道路上有过大挫折或重大转折 |
| 鼻头（准头）有痣 | 财运有波折，容易有意外花销 |
| 鼻翼有痣 | 理财观特别，可能极节俭或极大方 |
| 鼻下（人中之侧）有痣 | 需注意饮食健康 |

---

## 综合分析注意事项

1. 痣的吉凶不能只看位置，颜色、光泽、凸起程度同样重要
2. 同一区域多颗痣需要综合判断
3. 面相中的痣需与整体五官配合分析
4. 现代医学角度看，注意观察痣的变化（大小、颜色、形状），如有异常建议就医
