# 五官面相详解

传统面相学中，五官对应五脏和五行，各有其「官名」和核心寓意。

---

## 五官速查表

| 五官 | 官名 | 五行 | 对应内脏 | 核心寓意 |
|------|------|------|----------|----------|
| 眉 | 保寿官 | 木 | 肝 | 健康长寿、人际关系 |
| 眼 | 监察官 | 火 | 心 | 智慧、心性、善恶 |
| 鼻 | 审辨官 | 土 | 脾 | 财运、自我、中年运 |
| 口 | 出纳官 | 水 | 肾 | 福禄、晚年运、言语 |
| 耳 | 采听官 | 金 | 肺 | 福气、早年运、寿命 |

## 眉 — 保寿官

眉为「保寿官」，主健康长寿与兄弟朋友缘。

### 眉毛形态等级

**上等眉形：**
- 眉长过目：兄弟朋友多，人缘广，寿命较长
- 眉清而秀（根根见底）：为人清正，心性善良
- 眉有彩（眉内有光泽）：健康状态佳，精力充沛
- 眉尾聚而不散：做事有始有终

**中等眉形：**
- 眉粗浓但整齐：性格刚烈，重情义
- 眉毛淡但清秀：性格温和，有文艺气质
- 眉毛短但有型：性急但能力强

**下等眉形：**
- 眉低压眼：性格压抑，运势受阻
- 眉尾散乱：做事不能持久，容易半途而废
- 眉毛逆生（往上竖）：性格叛逆固执
- 眉毛中断：兄弟朋友缘薄或健康需注意
- 眉头带箭（眉头有尖刺状毛发）：性格暴躁

### 特殊眉相
- **眉有长毫（眉尾有特别长的眉）**：寿相，但仅限40岁以后出现才是吉兆，年轻时出现反而不利
- **眉有白毫（眉毛变白）**：长寿之征
- **双眉入鬓（眉尾深入太阳穴方向）**：有威严，地位高

## 眼 — 监察官

眼为「监察官」，是面相中最重要的部位，主智慧善恶与35-40岁运。

### 眼神（最重要，超越眼形）

**上等眼神：**
- 目光藏而不露，有神而不刺人：大智慧，藏锋于内
- 目光柔和坚定：心地善良，有定力
- 眼神清澈明亮如秋水：心地纯正，品性高洁

**中等眼神：**
- 目光直接但不锐利：性格直爽
- 目光温和偏柔：性格温和善良但缺乏魄力

**下等眼神：**
- 四白眼（黑眼珠四周露白）：性格极端，有暴力倾向
- 三白眼（黑眼珠上方或下方露白）：性格偏激或运势起伏大
- 目光混浊昏暗：精力不济，运势低迷
- 目光凶狠：心术不正
- 目光不断游移：心思不定，有不可告人之事

### 眼形

| 眼形 | 特征 | 性格解读 |
|------|------|----------|
| 龙眼 | 大而有神，眼尾上翘 | 大贵之相，聪明果断 |
| 凤眼 | 细长微挑，黑白分明 | 聪慧高贵，品位不凡 |
| 桃花眼 | 眼尾微弯似笑 | 异性缘旺，感情经历丰富 |
| 杏眼 | 圆而大，眼尾微垂 | 天真单纯，善良可爱 |
| 三角眼 | 眼形呈三角 | 城府深，有心机 |
| 鼠眼 | 小而圆，目光闪烁 | 机敏但略猥琐，不可信 |
| 羊眼 | 眼珠偏黄，眼白多 | 性格固执偏激 |
| 牛眼 | 大而圆，眼白少 | 性格憨厚老实 |

### 眼周特征
- **卧蚕饱满**（眼下微隆）：人缘和桃花运的标志，异性缘好
- **泪堂饱满**（眼下位置）：子女运佳
- **鱼尾纹（眼角纹）**：
  - 向上：桃花运旺，异性缘好
  - 向下：感情上容易受伤或为人付出多
  - 杂乱：感情生活比较复杂
- **眼袋明显**：精力透支，需注意休息

## 鼻 — 审辨官

鼻为「审辨官」，主财运与自我，也为「财帛宫」和「夫星」（对女性而言看丈夫）。

### 鼻梁

| 鼻梁形态 | 解读 |
|----------|------|
| 鼻梁高挺笔直 | 自信果断，事业心强，中年运旺 |
| 鼻梁适中 | 性格正常 |
| 鼻梁低塌 | 自信心不足，运势平淡，需靠后天努力 |
| 鼻梁有节（有明显骨节突起） | 性格刚烈固执，人生有大的转折 |
| 鼻梁弯曲 | 人生道路有波折 |

### 鼻头（准头）

- **圆润饱满有肉、鼻孔不外露**：最佳鼻头，财运好且能守财
- **尖削无肉**：财运一般，性格计较
- **鼻头下垂（鹰钩鼻）**：精明善算计，事业有成但可能心机重
- **鼻头过小**：财运较差，缺乏自信
- **鼻孔朝天（仰鼻）**：容易漏财，性格大方但不会理财

### 山根（鼻梁起点，两眼之间）

- **高挺饱满**：事业根基好，运势畅通，自信
- **低陷**：早年辛苦，自信心偏弱，事业起步较难
- **有横纹截断**：中年有较大波折

### 鼻翼（兰台、廷尉）

- **鼻翼饱满有收**：理财能力强，有储蓄意识
- **鼻翼薄弱**：容易漏财，不善于守财
- **鼻翼宽大展开**：人缘好但花钱大手大脚
- **鼻翼大小不一**：理财观念摇摆不定

## 口 — 出纳官

口为「出纳官」，主福禄、晚年运势和言语。

### 大小
- **口大（超过两眼瞳孔垂直线）**：性格豪爽，有魄力，福气好
- **口适中**：正常
- **口小（窄于两眼瞳孔垂直线）**：性格谨慎内向，福气一般

### 形状
- **口角上扬（仰月口）**：性格乐观开朗，晚年运势好
- **口角下垂（覆舟口）**：性格悲观，晚年运势偏弱
- **唇线分明**：为人有原则，说话算数

### 嘴唇
- **上下唇均饱满红润**：性格好，福气佳，人际关系好
- **上唇厚下唇薄**：重感情付出，容易被利用
- **上唇薄下唇厚**：享受型，偏自我
- **嘴唇干裂苍白**：体质偏弱或运势低迷

### 牙齿
- **牙齿整齐洁白**：口福好，说话有分量
- **牙齿稀疏或歪斜**：言语上容易得罪人，口福一般

## 耳 — 采听官

耳为「采听官」，主福气与早年运（1-14岁）。

### 大小
- **耳大而厚（大过眉毛）**：福气深厚，长寿之相
- **耳适中**：正常
- **耳小且薄**：早年运势一般，福气偏薄

### 耳垂
- **耳垂大而厚实**：福气极佳，晚年安逸，有佛缘
- **耳垂适中**：正常
- **没有耳垂或耳垂极小**：福气一般

### 耳廓
- **耳廓分明（耳轮与耳甲清晰分离）**：为人有主见，独立性强
- **耳廓不明显**：性格随和，易受他人影响

### 耳位
- **耳高于眉**：天资聪颖，有贵人运
- **耳与眉齐**：正常
- **耳低于眉**：早年运势一般，需要更努力

### 耳朵颜色
- **耳色白于面**：聪慧有福，贵相
- **耳色红润**：身体健康，运势旺
- **耳色暗淡**：精力不济或运势低迷

### 耳形特殊标记
- **耳朵贴脑（招风耳的相反）**：性格稳重踏实，但可能保守
- **招风耳（耳朵外翻）**：性格独立好动，不安于现状

---

## 五官综合评估框架

1. **眼最重要**：眼神好坏决定整体面相的基调
2. **鼻次之**：鼻决定中年运势和物质基础
3. **眉看健康与人脉**
4. **口看晚年和福气**
5. **耳看根基和寿命**

**基本法则：** 五官端正、比例协调为佳；任何一个器官过于突出或不足都需要综合平衡来看。
