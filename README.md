# palm-and-face-reading-skill

Marvis 赛博相师技能——基于中国传统相学的手相与面相分析助手。

## 功能

- 上传手掌照片自动分析掌形、掌纹、掌丘、手指
- 上传面部照片自动分析脸型、三停、五官、十二宫、痣相
- 支持双手对比分析（左先天/右后天）
- 支持手面相结合交叉印证
- 手动输入特征描述也可分析
- 自动识别照片类型（手部/面部），批量多张照片自动排程
- 照片真实性甄别（AI生成/卡通/绘画等非真人照片自动拦截）

## 使用方式

在 Marvis 中直接上传手部或面部照片，或输入「帮我看手相」「帮我看看面相」等触发词即可。
